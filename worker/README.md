# Servicio gratuito de NutriDuo

La web sigue en GitHub Pages. Este Worker sólo recibe las fotos y descripción que la persona decide analizar. No recibe PIN, perfil, peso, objetivos ni historial. No almacena fotos, prompts ni respuestas y tiene logs desactivados. Groq procesa el análisis. La búsqueda nutricional usa un catálogo oficial incluido; si se configura una clave USDA opcional, ese servicio recibe únicamente el término de búsqueda de un alimento.

## Activación

1. Cuenta **Groq Free**, sin añadir método de pago ni cambiar a Developer. Crear una API key llamada `NutriDuo`. Activar Zero Data Retention en los controles de datos de Groq si se quiere evitar la retención excepcional por errores/abuso.
2. Cuenta **Cloudflare Workers Free**. Usa Workers AI Free (10.000 neuronas diarias) sólo como respaldo cuando Groq se queda sin cuota; no usa servicios pagos. Publicar con `npx wrangler deploy --config worker/wrangler.jsonc`. La cuenta configurada es la indicada por el usuario; el proyecto usa un único Worker `nutriduo-ai`. Si se usa OAuth de Wrangler, el usuario debe aprobar el acceso en su navegador.
3. Guardar `GROQ_API_KEY` como **Secret** en Cloudflare, nunca en Vite, GitHub, el navegador de NutriDuo ni el chat. Puede usarse el panel de Cloudflare o `npx wrangler secret put GROQ_API_KEY --config worker/wrangler.jsonc`, que pide el valor por stdin.
4. Generar un código aleatorio de al menos 32 caracteres y guardarlo como Secret `NUTRIDUO_ACCESS_TOKEN`. Este código sólo autoriza consultas al servicio personal; no es la clave de Groq ni el PIN de un perfil. Compartirlo únicamente con Luca y Ari.
5. Ya se incluyen 2162 fichas oficiales de alimentos comunes en `nutrition-catalog.json`. Se derivaron de [descargas USDA](https://fdc.nal.usda.gov/download-datasets/) Foundation Foods (abril 2026) y FNDDS (octubre 2024), CC0; el script `scripts/build-nutrition-catalog.mjs` reproduce el catálogo sin credenciales. Esta búsqueda no consume una cuota de API ni requiere otra cuenta. Opcional para un catálogo más amplio: obtener una clave gratuita propia de [FoodData Central](https://fdc.nal.usda.gov/api-key-signup/) y guardarla como Secret `USDA_API_KEY`. No se utiliza DEMO_KEY en producción.
6. NutriDuo → Más → Análisis de comidas → ingresar el código de conexión. La versión de GitHub Pages ya incluye `https://nutriduo-ai.lucarighetti2000.workers.dev`; otros builds pueden definir `VITE_AI_ENDPOINT` o ingresar la URL HTTPS manualmente. **Recordar conexión en este dispositivo** viene activado: se comparte el acceso de análisis entre los perfiles en ese celular, conservando separados los registros. Al abrir la sección se comprueba `/health` y se muestra el estado; un fallo de red no elimina el código. Desconectar borra el acceso del dispositivo. No se exportan credenciales en backups.

Los comandos de configuración solicitan secretos interactivamente. No ponerlos como argumentos, valores VITE_, archivos versionados ni mensajes. Las pruebas usan credenciales ficticias; no necesitan una cuenta.

## Límites y funcionamiento

- Modelo fijo `qwen/qwen3.8-27b`, salida JSON y hasta 1400 tokens de respuesta (Groq Free cuenta la reserva de salida dentro de 8.000 tokens por minuto). Si Groq responde 429 con espera de hasta 12 s, se reintenta una vez; si sigue sin cuota o falla, se usa `@cf/meta/llama-4-scout-17b-16e-instruct` de Workers AI Free. El cliente no puede elegir modelos o instrucciones del sistema.
- `/analyze` acepta `{photos, description}` y el formato anterior `{photo, description}` para instalaciones pendientes de actualización. Hasta tres imágenes de 2 millones de caracteres cada una; cuerpo máximo de 6,1 MB. La app conserva cada foto por separado y envía al análisis copias de 1024 px como máximo; cuando hay más de dos, genera hasta dos láminas numeradas de 1280 px. Así una consulta usa unos 2.000-3.000 tokens en lugar de superar sola el límite por minuto. Muchas fotos reducen el detalle disponible por etiqueta: el análisis debe preguntar cuando el texto no sea legible. El prompt evita contar varias vistas de un plato o un envase completo como consumo adicional.
- 20 solicitudes por minuto y ruta en cada ubicación de Cloudflare. Este límite local protege de ráfagas; no es una cuota global. También se aplican las cuotas de Groq de la organización y el límite del plan Workers Free.
- Un único reintento corto y un respaldo gratuito (Workers AI); no hay proveedores pagos ni cambios de plan. Un HTTP 429 mantiene el formulario para volver a intentar o cargar manualmente. El costo depende de conservar ambas cuentas en sus planes gratuitos; la app no puede comprobar ni modificar el plan de facturación de terceros.
- Solicitudes autorizadas con código y origen permitido. CORS no sustituye la autenticación. Rutas `/health`, `/analyze` y `/nutrition/search`; cuerpos limitados y validados, sin URLs de fotos remotas.
- JSON mal formado, macros imposibles para el esquema o respuestas truncadas se rechazan. Nada se guarda automáticamente. Las incertidumbres se presentan como preguntas antes de confirmar.
- La IA sólo estima macros. No inventa vitaminas ni minerales. La persona elige una ficha USDA que coincida con alimento y cocción; esa ficha reemplaza valores por 100 g y agrega micronutrientes presentes. Una referencia de base no verifica la identidad ni el peso del plato fotografiado.
- Micronutrientes ausentes quedan ausentes; 0 se conserva sólo si aparece en la fuente. Los totales parciales indican cuántos componentes aportan datos. Fibra ausente conserva una marca de falta de dato aunque el motor legado la excluye del total numérico.

## Verificación

`npm test`, `npm run lint`, `npm run build`, `npm run test:e2e` y `npx wrangler deploy --config worker/wrangler.jsonc --dry-run`. Los tests de servidor y navegador simulan respuestas del proveedor y verifican autorización, límites, aclaraciones, selección de fichas y revisión. La activación se comprobó además en el servicio publicado: sin código devuelve 401, otro origen devuelve 403, health y búsqueda devuelven 200, y una foto pública de una banana con porción indicada devuelve componentes válidos de Groq. Una imagen que no era comida produjo preguntas de aclaración. Estas pruebas verifican disponibilidad y contrato; no establecen precisión nutricional para platos reales.

## Recordatorios gratuitos con la app cerrada

Web Push usa el mismo Worker, una suscripción estándar del navegador, firma VAPID y KV. El PDF, las comidas, el peso y los objetivos no se envían al servicio de recordatorios. Los mensajes son genéricos. Se permiten hasta ocho dispositivos; las rutas de configuración usan el mismo código de acceso, validación de suscripciones y límites de solicitudes. Los endpoints se restringen a servidores de Chrome/Firefox/Apple para evitar destinos arbitrarios.

1. Wrangler necesita `workers_kv:write`, además de los permisos previamente autorizados para publicar el Worker. Crear un namespace KV y enlazarlo como `PUSH_SUBSCRIPTIONS`.
2. `node scripts/setup-push.mjs` genera claves VAPID en `.wrangler/`, fuera de Git. Prepara la clave pública, la compatibilidad Node y el cron cada cinco minutos. `--publish-secret` guarda la clave privada como secreto, sin imprimirla. No rotar las claves de una instalación activa sin renovar las suscripciones.
3. Publicar el Worker. La programación usa Buenos Aires: pesaje 06:50, salida 07:10, desayuno 08:30, almuerzo 13:00, merienda 17:00, fuerza martes/viernes 18:00, cena 21:00 e informe domingo 19:30. Las categorías se activan o desactivan desde cada dispositivo. Un aviso no detecta si ya se registró el dato: no se comparte el historial local.
4. Abrir la app instalada → Más → Recordatorios → Activar. El permiso se solicita desde ese botón. En iOS es necesario agregar la app a Inicio; la entrega depende de conexión y configuración del sistema. Enviar aviso de prueba permite comprobar la recepción sin esperar al cron. Desactivar elimina la suscripción del servidor y del navegador. Una suscripción vencida se elimina cuando el proveedor responde 404/410.

El cron hace como máximo 288 listados de KV por día y los envíos dependen de las categorías y dispositivos activados. Se conserva Workers Free/KV Free, sin agregar medio de pago ni proveedor pago. Si se agota la cuota, pueden fallar los avisos: no hay cambio automático de plan. La firma/cifrado, deduplicación y eliminación de suscripciones se verifican con pruebas; la recepción física debe verificarse en cada celular después de conceder permiso.
